## Dataset

### Iris Flower Dataset

The Iris dataset contains measurements of different Iris flowers.

It includes **150 samples** belonging to three different flower species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

Each sample contains four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The target variable represents the flower species.

---

## Machine Learning Problem

This project is a **classification problem**.

The goal is to predict the species of an Iris flower based on its physical measurements.

```text
Sepal Length
Sepal Width
Petal Length
Petal Width
       ↓
  KNN Model
       ↓
Flower Species
````
