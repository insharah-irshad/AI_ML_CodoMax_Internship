# Module 3 — Data Analysis & Visualization

**CodoMax AI/ML Internship**

**Level:** Intermediate  
**Duration:** Day 9 – Day 12

## Overview

This module focuses on the fundamentals of data analysis and visualization using Python.

The project uses a sample sales dataset to explore data, perform basic cleaning and analysis, and create visualizations using Pandas, NumPy, and Matplotlib.

## Objectives

- Work with datasets using Pandas and NumPy
- Explore and understand dataset structure
- Perform basic data cleaning
- Analyze sales data
- Create meaningful data visualizations
- Interpret basic insights from the dataset

## Libraries Used

- Python
- NumPy
- Pandas
- Matplotlib
- Google Colab

## Data Analysis

The following analysis was performed:

- Dataset exploration
- Dataset shape and column inspection
- Statistical summary
- Missing value detection
- Duplicate detection
- Date formatting
- Total sales calculation
- Average sales calculation
- Highest and lowest sales
- Product-wise sales analysis
- Category-wise sales analysis
- Best-selling product identification

## Visualizations

### Bar Chart

Shows total sales by product category.

### Line Chart

Shows the sales trend over time.

### Pie Chart

Shows the percentage distribution of sales across product categories.
