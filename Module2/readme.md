## Project: Expense Tracker

This project is a beginner-friendly command-line Expense Tracker built using Python.

The purpose of this project is to apply fundamental Python programming concepts by building a practical, menu-driven application.

## Features

- Add a new expense
- View all recorded expenses
- Calculate total expenses
- Interactive command-line menu
- Input validation for menu choices
- Continuous program execution until the user exits

## Concepts Used

- Variables
- User input
- Data types
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- Arithmetic operations
- Formatted output

## How It Works

The application displays a menu with four options:

```text
1. Add Expense
2. View Expenses
3. Calculate Total
4. Exit

```

## Add Expense

The user enters:

Expense name
Expense amount

The information is stored in a list using a dictionary.

View Expenses

The application displays all recorded expenses with their corresponding amounts.

Calculate Total

The application calculates and displays the total amount of all recorded expenses.

Exit

The application terminates when the user selects the exit option.

### Example
===== Expense Tracker =====
1. Add Expense
2. View Expenses
3. Calculate Total
4. Exit

Enter your choice: 1
Enter expense name: Food
Enter expense amount: 500
